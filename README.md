# AI Super Agent 0.1\n\nA small, provider-neutral TypeScript agent runtime with a browser chat interface.\n\n## Included\n\n- Fastify HTTP API with `/health`, `/tools`, and `/chat`\n- OpenAI-compatible model adapter using `LLM_BASE_URL`\n- Mock mode that runs before credentials are configured\n- In-process conversation memory (last 20 messages per conversation)\n- Browser chat UI served from `/`\n- Example tools: `health` and `list_tools`\n\n## Run locally\n\n```bash\nnpm install\ncp .env.example .env\nnpm run dev\n```\n\nOpen `http://localhost:3000` in a browser. The default mock mode is immediately usable.\n\n## Connect a real model\n\nSet these values in `.env`:\n\n```env\nLLM_PROVIDER=openai\nLLM_BASE_URL=https://api.openai.com/v1\nLLM_API_KEY=your-key\nLLM_MODEL=gpt-4o-mini\n```\n\nAny provider with an OpenAI-compatible `/chat/completions` endpoint can be used by changing `LLM_BASE_URL` and `LLM_MODEL`.\n\n## Next build steps\n\n1. Persist conversations in Postgres.\n2. Add streaming responses and run traces.\n3. Add authenticated tool execution and approval policies.\n4. Add more provider adapters and deploy it.\n
